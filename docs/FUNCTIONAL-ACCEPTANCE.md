# 日报助手功能清单

更新日期：2026-09-20。面向业务、实施与研发人员。

## 1. 方案与业务边界

采用「企微机器人＋PC 后台＋移动周报 H5＋服务器数据库」方案。员工通过企微记录工作，后台维护人员和企业，管理者通过周报了解业务进展、给出反馈，机器人将反馈通知员工。

**目标是人员、正式企业、新企业、计划、日报、周报与反馈统一存入服务器数据库，不依赖企微文档完成业务闭环。**当前新企业专用流程仍依赖企微表，需改接数据库。以下是目标功能清单，包含待实现部分，不代表全部已经完成。

| 产品入口 | 主要职责 |
| --- | --- |
| 企微机器人 | 引导绑定、收集计划日报、企业识别、新企业搜索与确认、提醒与反馈通知 |
| PC 后台 | 人员和汇报关系、企业档案、新企业管理、工作记录、模板规则、知识和日志 |
| 员工移动周报 | 个人摘要、事项成果、未完成原因、计划外工作和老板反馈 |
| 老板移动周报 | 团队进展、事项与员工视角、个人周报、新企业信息及反馈 |
| 服务器数据库 | 统一保存业务数据、确认状态、关联关系和历史 |

本轮不包含：全部业务数据写企微文档、智能表格自动归档、完全脱离企微的 PC 独立办公、多实例高可用。当前 PC 日报录入形成草稿，正式确认及员工工作台入口仍与企微配合。

状态说明：**已有**表示有代码能力，不代表客户环境已验证；**待补齐**表示仍有开发缺口；**待对齐**表示基础能力已有，需符合确认后的业务口径或交互。未实现功能仍纳入范围。

## 4. 新企业搜索与录入

完整流程：**员工提及企业 → 匹配已有档案 → 未匹配时联网搜索 → 员工核对补充 → 确认写入数据库新企业表 → 后台维护及周报查看 → 转为正式企业。**

| 功能 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 新企业识别 | 同时匹配正式企业与已确认新企业，已有档案复用，避免重复创建 | 待补齐数据库流程 |
| 企业信息搜索 | 实际检索公开资料，形成待核对候选，不以模型猜测冒充检索；不向搜索服务发送内部需求或联系人电话 | 已有搜索基础，待接数据库 |
| 同名企业核对 | 根据全称、所在地等引导员工选择，不混用不同企业资料 | 待补齐 |
| 补充与更正 | 简洁展示候选，允许补充企业情况、需求和跟进；未知内容留空 | 已有对话基础，待接数据库 |
| 人工录入兜底 | 搜索失败或无可靠结果时允许人工补充确认，不阻断日报 | 已有对话基础，待接数据库 |
| 待确认资料保存 | 保存补充内容和状态，重启后继续；未确认不生成正式的新企业档案 | 待补齐 |
| 确认入库 | 员工明确确认后写入数据库新企业业务表，保存稳定标识及关联 | 待补齐 |
| 防重复与失败恢复 | 重复确认不重复建档，多人录入核对冲突，失败不提示成功 | 待补齐 |
| 后台新企业管理 | 新企业列表、查询、详情、资料维护和相关工作记录入口 | 待补齐 |
| 周报企业弹窗 | 点击新企业名称读取数据库资料，展示业务信息 | 已有文档版基础，待改数据库 |
| 转正式企业 | 授权人员转入正式名单，保留原资料、标识和历史关联，不重复建档 | 待补齐 |
| 转正式后联动 | 按当前状态取消周报新企业弹窗入口，保留企业名称和历史工作内容 | 待补齐 |
| 新企业权限 | 限制查看、维护与转正式权限，联系人电话不进入公开周报 | 待补齐数据库流程 |

弹窗标题为“企业信息”，顶部展示跟进人和最近拜访日期，正文采用三段文本描述，不堆砌表单字段：

| 内容 | 信息范围 |
| --- | --- |
| 企业情况 | 行业、主营业务、员工规模、注册资本及币种、法定代表人、注册地址 |
| 企业需求 | 意向区域、用房面积和预算、政策或资源对接需求、预计落地时间 |
| 跟进安排 | 当前阶段、下一步行动、计划时间及需要协调的事项 |

只保存已知信息，不要求一次填全，不推测缺失字段。联系人、联系方式可选填，仅授权后台可见。资料来源可内部留存，不作为老板弹窗重点内容。

企业建档确认与日报确认相互独立：确认日报不等于确认新企业，确认新企业也不代表工作已正式记账；取消建档不删除日报原文。

## 5. 周计划与日报

| 功能 | 功能说明 | 当前状态 |
| --- | --- | --- |
| 每周计划 | 按自然周创建本人事项，维护背景、目标数量和单位 | 已有 |
| 计划修订 | 修改保留历史，按现有规则限制已锁定事项删除 | 已有 |
| 企微工作录入 | 接收文字及附件消息，保留原文；附件理解范围取决于支持格式 | 已有 |
| AI 整理日报 | 提取成果、企业、进展、问题和下一步，生成待确认草稿 | 已有 |
| 文字确认与修改 | 员工核对、修改、确认后计入正式记录 | 已有；PC 旧卡片提示待修正 |
| 当日补充 | 补发形成更新草稿，再次确认，保留历史且不重复计数 | 已有 |
| PC 结构化录入 | 按事项填写工作事实，保存草稿后在企微确认 | 已有 |
| 进度计算 | 区分增量与累计，按计划计算完成率，支持去重和更正 | 已有 |
| 未知进度 | 缺少事实不当作零，也不推定完成 | 已有 |
| 企业关联 | 确认后关联匹配企业；学习等不涉及企业的工作不强制关联 | 已有 |
| 计划外工作 | 单独记录临时工作，不误计入原计划，电话咨询不算走访 | 待对齐 |
| 异常保护 | 模型异常保留原文，不形成正式半成品，避免无限重试 | 已有 |

事项分类统一为：**重点企业完成进度、培训与活动、企业服务与对接、综合事务、其他工作**。动态周报分组和布局已调整，录入、统计与明细仍需统一口径。
